## 2026-11-27 — RAG: BM25 + LLM, benchmark (КТ3)
- Корпус `corpus/` из 30 документов D01–D30 (карточки коворкингов из `data.js` + правила, цены, услуги), все данные вымышленные.
- `backend/rag/`: своя предобработка (регистр, пунктуация, стемминг, служебные слова), свой BM25-индекс по формуле методички, загрузка корпуса, клиент OpenAI-совместимой LLM и офлайн-заглушка, пайплайн `retrieve → build_context → build_messages → llm` с отказом «В документах нет этой информации.»
- `backend/app.py`: FastAPI `POST /api/ask`, `GET /api/health`, раздача `frontend/`; `backend/ask.py` — вопрос из терминала.
- Интерфейс: вопросы по документам и непонятые фразы отправляются в `/api/ask`, ответ показывается со списком источников; бриф не меняется. В «О проекте» обновлено, что работает.
- `benchmark/`: 10 вопросов + 5 ловушек с эталонами, `run.py` (Recall@3/@5, MRR@5, Accuracy, Correct Rejection Rate), результаты и разбор ошибок.
- `tests/test_rag.py`: пример из методички (A = 0,940, B = C = 0,470), насыщение tf, отказ, источники.
- Обновлены README, `backend/README.md`, `benchmark/README.md`, `spec/tech/rag.md`, `tests/README.md`.

**Проверка:** `python -m unittest discover -s tests` — 10/10; `node tests/assistant.test.js` — 16/16; `python benchmark/run.py` (офлайн): Recall@3 0.578, Recall@5 0.752, MRR@5 1.000, Accuracy 0.5, CRR 1.0. В браузере (http://localhost:8000/, 1280px): вопрос о парковке → ответ с источниками D18, D19; «можно ли с собакой?» → отказ; бриф после этого продолжается; ошибок в консоли нет.

**Ограничения:** прогон с настоящей LLM не выполнен (нужен ключ); стемминг простой, синонимов нет; числовые условия поиск не проверяет; бриф по-прежнему на правилах.
