# Backend

Backend на Python с использованием FastAPI.

На КТ1 серверной части нет: сайт работает полностью в браузере.

Планируемая роль backend (см. `spec/tech/architecture.md`, раздел 4, и `spec/tech/rag.md`):

- принимать сообщения пользователя от `frontend/`;
- искать релевантные документы корпуса через BM25;
- передавать найденный контекст в LLM и возвращать ответ с источниками;
- (по возможности) хранить бронирования.

Интерфейс уже ожидает ответ в формате из `spec/tech/rag.md` (раздел 12): текст, следующий вопрос, метки условий, рекомендации с `docId`. При подключении достаточно заменить вызов `respond` в `frontend/app.js` на запрос к API.
