# CoworkingFinder

Учебный проект: сервис поиска и демонстрационного бронирования коворкингов с RAG-помощником.

## Для кого
Студенты, фрилансеры, удалённые сотрудники и небольшие команды, которым нужно подобрать рабочее место.

## Основной сценарий
1. Пользователь открывает каталог.
2. Уточняет требования (город, цена, удобства) или вводит текстовый запрос.
3. Просматривает подходящие варианты и подробности.
4. Выбирает дату и нажимает «Забронировать».
5. Получает **демонстрационное** подтверждение без сохранения брони на сервере.

## Что готово
- Документация SDD в `spec/`.
- Работающий локальный HTML/CSS/JS-прототип в `frontend/`.
- Демонстрационные данные в `frontend/data.js`.
- Правила работы с репозиторием и история изменений.

## Как запустить
Откройте файл `frontend/index.html` двойным щелчком в браузере.
Интернет, установка зависимостей и сервер не требуются.

## Ограничения
- Поиск в прототипе — простой поиск по словам и фильтрам, **не BM25**.
- ИИ-помощник демонстрирует заранее подготовленный ответ, **не вызывает LLM**.
- Бронирование имитируется в браузере, **не сохраняется**.
- Все названия, адреса, цены и характеристики коворкингов вымышленные.
