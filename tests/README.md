# Тесты

## Автоматические
```bash
node tests/assistant.test.js
```
Проверяют движок консультанта `frontend/assistant.js`: разбор условий, ход брифа, пропуск вопросов, снятие условий, итог, сравнение, ссылки на источники. Зависимости не нужны (Node.js 18+).

Когда движок заменят на вызов backend/RAG, эти тесты стоит сохранить как проверку формата и правил ответа (см. `spec/tech/rag.md`, раздел 12).

## Ручная проверка интерфейса
Открыть `frontend/index.html` и пройти:

1. Старт: короткое приветствие и вопрос «В каком городе?», справа подборка 10/10, метка «демо» в шапке.
2. «Москва» → «до 800 ₽» → отметить «Переговорная» → «Готово» → «Только я». После каждого ответа помощник задаёт только следующий вопрос; счётчик 4 → 3 → 2, метки условий, неподходящие места гаснут и уходят вниз, прогресс брифа заполняется.
3. Итог одной строкой: «Лучшее — «Точка Сборки»: 700 ₽, переговорная.», на плитке метка «лучшее», кнопки «Забронировать», «Сравнить», «Новый бриф».
4. «Сравнить» — таблица из двух мест.
5. «Забронировать» → выбрать дату → «Забронировать (демо)» — билет `DEMO-…` в карточке и сообщение в разговоре. Без даты кнопка неактивна.
6. «Новый бриф» → написать «круглосуточно в Казани» — 0 совпадений, кнопки «Убрать: …»; на плитках — «не хватает: …». Снять «Казань» (кнопкой или «×» на метке) — 2 места.
7. Пустое сообщение не отправляется; «asdf» — помощник повторяет текущий вопрос.
8. Перезагрузить страницу — бриф восстановился.
9. Переключить тему; сузить окно до ширины телефона — подборка открывается кнопкой «Подборка N/10» в шапке.
